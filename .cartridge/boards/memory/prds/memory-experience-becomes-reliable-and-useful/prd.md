## Integration gate

All owned children and referenced cross-owner leaves must pass their acceptance, collected tests, migration/recovery checks and independent plan review. Demonstrate a healthy request entering durable memory, crystallizing, being retrieved/read back through the public consumer, and appearing with accurate status in ASP/Scope. Repeat with model outage, stale commit and restart. Run the labelled quality and latency gate before changing semantic thresholds or ranking defaults.

No implementation is claimed complete here. Exact replay of discarded variants, semantic causal correctness and improved real agent outcomes remain unproven. See [review](review.md), [investigation](investigation.md) and each leaf for evidence, limits and verification commands.
