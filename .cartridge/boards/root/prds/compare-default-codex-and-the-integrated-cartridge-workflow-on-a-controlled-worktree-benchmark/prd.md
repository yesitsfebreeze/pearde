# Compare default Codex and the integrated cartridge workflow on a controlled worktree benchmark

## Outcome

Run the same small coding task through native Codex and Codex with the cartridge proxy, tools, methods and JEV in two detached worktrees from one frozen commit. Publish measured outcomes without presuming an integration benefit. This directly requested benchmark serves the JEV and harness ranking rows.

- [x] Keep worktrees, sessions and runtime stores separate; do not publish hidden tests through ASP.

## Protocol

The frozen configuration-overlay task has seven explicit requirements and 32 independent behavioral/preservation checks. Its original public tests pass. Both Codex clients use gpt-6-astra at medium effort with a 600-second deadline. Native Codex tools remain available. A fresh integrated runtime adds frozen code, method records and empty memory, with strict routing to the same ChatGPT model. Sequential arm order is recorded. The first shared-source launch is retained as invalid because concurrent manifest edits disabled services; the scored pair uses frozen cartridge snapshots.

Predeclared quality review scores maintainability, regression-test strength and scope discipline separately, each out of five, blinded to arm labels. Requirement-claim precision is verified from BENCH_REPORT.json against acceptance checks, and transcript test claims are checked separately. One pair does not demonstrate statistical significance or warm-memory benefits. Full details live in .cartridge/bench/codex/README.md.
