## Inputs

One concrete choice, current source context and a measurable success criterion.

## Do

Read existing relevant knowledge through the configured memory service before
repeating research. Identify the decisive uncertainty, use a disposable fixture,
and compare options against the same task and environment. Record source versions,
commands, outputs, cost and limitations. Preserve durable stores and unrelated work.
Publish the finding as a PRD-owned decision with evidence; send any implementation
outcome through [[@prd/routine/plan-cartridge-work.md]].

## Check

The recommendation follows the measured criterion, and another worker can repeat
the measurement. Historical findings are distinguished from current observations.

## Failure

Record unavailable tools or inconclusive evidence. Do not invent measurements,
install alternate planning engines, or turn a recommendation into completed work.
