Every score page ends with **improve in this order**. Each line became one
page here, and each page is an **atomic unit of work**: one change, one
verifiable done, one honest fail shape — the shape an atomic workflow file
takes on the board (@@workflows).

A page is not a plan. It is the argument for one change: the failure it
removes, named where it happens; the change, small enough to hold in one
review; the state the tree can be checked in afterwards; and what breaks if
the change is done half-way. Whether it runs is the board's call — a page
becomes a PRD when someone wants it.

**Ordering: worst tool first.** Obsidian before view, view before scout —
the same rule the ranking keeps. Two tools' pages share one root cause
(state outside the board's files); those land first, because each unblocks
the other's smaller fixes.

suggested, counted, ranked over time, until an unused verb is a named row
