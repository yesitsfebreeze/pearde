Obsidian scores 45, the worst on the board. All three improvements attack the
same defect: the tool's state lives outside the board — in Obsidian's
register, in fetched plugin bundles — so a broken one reads exactly like a
working one and only doctor's `vault` row tells the difference.

## Why this tool first

Every other tool's failure is visible in the board's own files. Obsidian's is
not: an entry written under a running app dies on Obsidian's exit, and the
symptom — `Unable to find a vault for the URL` — names nothing local. Until
the register is checkable *and* repairable, every vault fix stays a
superstition.
