---

Knowledge is what the board learned outside the repo, as linked notes with
provenance: the board holds process and decisions, the wiki holds conclusions
and their sources — one home per question.

```
.pearde/wiki/
  sources/       external findings, one file per topic, raw
  conclusions/   synthesized answers, each derived from named sources
  pending/       research questions queued, priority-tagged
  graphs/        generated wiki pages over the KB
  Dashboard.md   live Dataview views over all of it
```

The loop is five verbs, all `knowledge.py`: **query** whether an answer is on
record, **remember** a finding with provenance, **conclude** once enough
sources agree, **relink** the note graph, **enqueue** a gap. Rules that
carry the layer: a source states, a conclusion argues; under two sources a
conclusion is refused as a hunch; wikilinks hold the graph together; the
vault is output — hand edits to `graphs/` die on the next `wiki`.
