# spec03 — the generated memo index reads dense

`resources/board/example/memos/README.md` is the one fixture in this PRD that
cannot be rewritten in the fixture. `render_index()` in @resources/memos.py
emits it byte-for-byte and `memos.py check` fails on any hand edit, so the
dense wording has to land in the generator. The banner it wrote read
`` `memo check` fails when it is stale `` — the vague-subject shape
`## Density` bans, and the last violation `prose.py check` reported in this
PRD's footprint.

Both directions are proven: leaving the fixture as generated fails
`prose.py check`; hand-editing it dense passes `prose.py check` and fails
`memos.py check` with `README.md: the kind index is stale`.

## Blast radius

Every board on this machine carries a `memos/README.md` written by the old
banner. Changing the generator makes each one stale until `memos.py index`
runs on it, and `resources/memos.py check` is one of the three gates
`settings.md` names, so the staleness is a red gate rather than a cosmetic
drift. This repo's own `pearde/` board is regenerated as a landing step
below; other boards are regenerated by their own next `memo add`, and
`pearde doctor` names the staleness meanwhile.

Measured on this machine, with the merged tree's generator against the shared
`pearde/` board: 38 lines, exit 1. Thirty-seven of them are another session's
in-flight `tags:` key and belong to no spec here; the thirty-eighth,
`README.md: the kind index is stale — run `memo index``, is this spec's, and
the landing step below is what clears it.

## What already stands

- The banner in `render_index()` reads `` `memo check` fails on a stale
  index ``, one string swapped for another of the same shape, on the lane.
- `resources/board/example/memos/README.md` regenerated from the generator,
  never by hand: `memos.py check` on a fresh `plan.py example` copy of the
  merged tree is silent, and `prose.py check` on the file exits 0.

## What is left

- Land the lane.
- Run `python3 resources/memos.py index pearde` in the checkout as a landing
  step, from the repo root, naming the board directory. A bare
  `memos.py index <repo root>` writes a stray `memos/README.md` at the root,
  because `find_board` matches any directory basename in `BOARD_DIRS` and
  this repo is itself named `pearde`.

## Struck box, and why

The earlier box 3 read `` `python3 resources/memos.py check` on this repo's
own board is silent ``. It is struck rather than re-run. `git ls-files
pearde` returns 0: the board is untracked, machine-local, shared by every
lane, carried by no merge, and rewritten by any concurrent `memo add` — the
worker closed it at 18:37 and another session reopened it at 19:56. Worse,
its colour is decided by a peer's uncommitted work: committed main's
`memos.py` reports 37 `tags:` failures against that board and exits 1, while
the checkout's uncommitted `memos.py` accepts them and exits 0. A box no
merge carries and no committed tree decides is not an acceptance box. Box 3
below replaces it with a board the generator owns end to end.
