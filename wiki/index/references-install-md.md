## Keywords

- `@@doctor` — telling a broken install from an absent one
- `@@guard` — the loop's rules, enforced rather than written
- `@@install` — putting every skill where this agent finds it
- `@@skills` — the entry points, what each is a door to, and how one is named
- `@@statusline` — the numbers rendered continuously in the terminal
- `@@update` — keeping every install of this repo current — the set of links, not the content
