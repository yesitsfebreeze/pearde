# resources/board/obsidian/

the vault preset — `.obsidian` root files (app, graph colors, community/core plugin lists, appearance), every path in them `.pearde/`-relative and the three required plugins' settings — including `plugins/hidden-folders-access/data.json`, whose `enabledFolders` names `.pearde` so the board is indexed by default and no other dot-folder is scanned; copied by `init` to any new board, an existing install wins. The plugin bundles (`main.js`, `manifest.json`, `styles.css`) are **not** in the repo: `pearde vault` fetches them at pinned versions and `.gitignore` holds them out
