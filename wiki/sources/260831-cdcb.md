# doctor-view-row-setu-deleted-variable

doctor view row, set -u and a removed variable: commit e628725 (the board row walks for `.pearde/`) deleted the `PBOARD` definition but the view rows grep still read `$PBOARD`; under `set -u` bash 3.2 does not abort the script, it prints `PBOARD: unbound variable` and the elif falls to `broken` — the everyday symptom is a false "the service is up but this board is not registered" on a board reached through a symlinked path (macOS /tmp vs /private/tmp), never a crash. Fix re-scopes the definition into the view block: PBOARD=$(cd "$BOARD" && pwd -P).
