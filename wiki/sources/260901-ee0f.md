# Every pearde board on this machine is on the .pearde layout

All nine rows of `resources/board/state/serve.json` now name a `.pearde/`
board dir. The seven that were still on the old `prds/` layout were migrated
in one pass on 2026-09-01 by the PRD's throwaway `migrate.py`, in the order
mitosys, model, realm, shared, manola, racer/.mi, then the infra master last
(its `members:` rows only rewrite once every member has moved).

PRD counts after the move, each equal to the prd.md-holding directory count
the board's old `prds/` held:

- /Users/feb/dev/infra/mitosys — 135
- /Users/feb/dev/infra/model — 82
- /Users/feb/dev/infra/realm — 19
- /Users/feb/dev/infra/shared — 17
- /Users/feb/dev/manola — 49
- /Users/feb/dev/racer/.mi — 48
- /Users/feb/dev/infra — 20 of its own, 273 merged over its four members
- /Users/feb/dev/dotfiles — 196, already migrated by hand before this run

Before the run all seven refused the gate with `pearde: no .pearde/ board at
<root>` (exit 2), so `scan`, `plan`, the view and the orphan scan were blind
to them.

Repo shapes worth knowing: `racer/.mi` is a board inside a dotdir of the
`racer` repo and is fully untracked — its move left the index untouched. The
other six committed their board, including the state dotfiles, so the move
landed as staged `R` renames (mitosys 303, manola 253, model 173, infra 118,
shared 70, realm 64). Nothing was committed in any of them.

Every board carried both a loose `prds/.history.jsonl` and a `prds/.state/`
history. The loose record wins the name; the loser is kept as
`.pearde/.state/history.jsonl.from-state-dir` on all seven.
