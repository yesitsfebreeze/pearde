# brew bundle check reports the machine, not the Brewfile

Measured 2026-09-02 on Homebrew 6.0.21, macOS 25.2.0.

`brew bundle check --file Brewfile` is not a check on the Brewfile. It
reports the state of the MACHINE, and goes red for causes that say nothing
about whether the file is correct:

- a formula that is merely OUTDATED (recurs upstream on its own, forever)
- a keg that cannot LINK because another installer owns a path — here,
  `docker` could not link `/opt/homebrew/etc/bash_completion.d/docker`,
  which Docker Desktop owns
- a cask whose artifacts are already on disk from another source — here, the
  CaskaydiaCove fonts in `~/Library/Fonts` differ byte-wise from the cask's
  own 3.5.1, so even `--adopt` refuses them

So a verify block asserting `brew bundle check` goes red for nothing and
teaches the reader to ignore it.

To check the FILE: `brew bundle list --file Brewfile --all` and resolve every
name with `brew info`. To check the MACHINE: `brew bundle check --no-upgrade`
and read the remainder as a to-do rather than a failure.
