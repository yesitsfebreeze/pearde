# tempfile.mkdtemp honours TMPDIR, so a fixture can scope a tool's scratch directory to its own run

collect.private_index calls tempfile.mkdtemp(prefix='pearde-index-'), and gettempdir() reads TMPDIR, TEMP, TMP in that order before falling back to /tmp. Measured on macOS 25.2 by e14-probe.sh: with TMPDIR set to a fixture-owned directory the scratch index landed at $TMPDIR/pearde-index-<rand> and was removed on exit. So a harness asserting that nothing is left behind can glob its own TMPDIR alone; the old glob over /tmp machine-wide was decided by whatever else on the machine happened to be inside a private_index at that instant, and read nothing about the tree under test.
