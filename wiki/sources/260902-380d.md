# a tmux popup binding cannot be tested on a detached server — it needs an attached client on a pty

`tmux new-session -d` gives a server with no attached client, and
`display-popup` is refused there — so a key binding that opens a popup reads
as broken on exactly the harness most convenient to reach for. `list-keys`
proves the binding parsed; it proves nothing about whether it dispatches.

The harness that works is `pty.fork()` with `tmux -f <conf> new-session` in
the child and the real escape sequence written to the master: `\x1bOR` for
F3, `\x1b[1;2R` for Shift+F3. Detect the result by having the bound command
touch a file — `capture-pane` does not capture the status line, so a
`display-message` probe reads as a failure that is not one.
