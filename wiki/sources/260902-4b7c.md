# cargo vendor ignores [source] config unless --respect-source-config

`cargo vendor --help` (cargo 1.9x, 2026-09-02) lists:

    --respect-source-config    Respect `[source]` config in `.cargo/config`

So by default `cargo vendor` IGNORES `[source]` replacement and resolves every dependency from its original source (registry or git); the flag is the opt-in to honour the replacement stanzas. `cargo build`/`check` always honour them.
