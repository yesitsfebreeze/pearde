# brew bundle skips an untrusted third-party tap and still exits 0

Measured 2026-09-02 on Homebrew 6.0.21, macOS 25.2.0.

A `brew "<user>/<tap>/<formula>"` line in a Brewfile is not enough on a
machine that has never trusted that tap. Homebrew refuses to load the formula:

```
Error: Refusing to load formula tinted-theming/tinted/tinty from untrusted
tap tinted-theming/tinted. Run `brew trust ...`
```

Two consequences that matter for provisioning scripts:

1. `brew bundle` will NOT trust a tap for you.
2. It does not fail the run. It prints the error and carries on, so
   `brew bundle install` exits 0 with the formula never installed. A fresh
   machine finishes green and silently missing the tool.

The fix is one line before the bundle: `brew trust --tap <user>/<tap>`.
Trust is machine state, stored in `~/.homebrew/trust.json`, not repo state,
so every machine needs it — a Brewfile cannot carry it.
