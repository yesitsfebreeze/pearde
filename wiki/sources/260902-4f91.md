# A PreToolUse hook that raises blocks the tool call, so a guard that can refuse must swallow every exception

A PreToolUse hook is answered by what it prints on stdout: a JSON `hookSpecificOutput` carrying `permissionDecision`. An uncaught exception prints a traceback on stderr and no decision, and the tool call does not proceed.

Consequence for any refusal that runs inside one: it must be wrapped whole, and a module that will not import or will not answer must deny NOTHING rather than propagate. A missed refusal costs one command; a raised hook costs the whole session the tool.

Measured 2026-09-02 while wiring `resources/board/refuse.py` into `resources/guard.py` on the pearde board. The same file already carries the sibling rule for `SessionStart` — a SessionStart hook exiting 2 prevents the session from starting.
