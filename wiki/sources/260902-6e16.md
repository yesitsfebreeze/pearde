# macOS ships no timeout(1) — perl's alarm is the portable bound in a probe

`command -v timeout gtimeout` returns nothing on this machine: macOS ships neither, and GNU coreutils is not installed. A probe that bounds a command which might hang cannot reach for `timeout 20 …` — the whole line fails, and a harness reads that as the bounded command failing rather than as a missing tool.

The portable bound is perl's alarm, and perl is on the base system:

```sh
perl -e 'alarm 20; exec @ARGV' python3 ramp.py need --board "$B"
```

It exits non-zero on the alarm the same way `timeout` does, so an assertion written against `timeout` needs no other change.
