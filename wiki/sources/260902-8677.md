# macOS has no setsid(1) — a probe makes its own session with os.setsid in Python

macOS ships no setsid(1), so a shell probe that needs its own process group
must make one in-process: `python3 -c "import os,sys;os.setsid();os.execv(sys.argv[1],sys.argv[1:])" /bin/bash script.sh`.
Measured 2026-09-02 on Darwin 25.2.0 while probing leaked serve.py daemons: `setsid bash fixture.sh` is `command not found`,
and without a session of its own `kill -9 -- -$PID` cannot reach the fixture and everything it spawned.
Related: subprocess.Popen(start_new_session=True) puts a child in its OWN session, so it is never reached by a kill of the parent group at all.
