# pipefail propagates a returned non-zero, never a printed failure

`set -o pipefail` makes a pipeline's status the last non-zero status any member
RETURNED. It carries nothing from a member that reports failure by PRINTING and
exits 0. So `probe.sh | tail -1` is a check only if `probe.sh` raises; a probe
ending on `echo "$PASS passed, $FAIL failed"` exits 0 whatever `$FAIL` holds,
and the pipeline is green on a broken tree.

Two further shapes measured green-on-broken under `-e -o pipefail`:
  `export VAR=$(pipeline)` — `export`'s own 0 masks the substitution's status
    (a bare `VAR=$(pipeline)` does inherit it).
  `probe | head -N` — `head` truncates the failure line away and its early exit
    races the writer's SIGPIPE, so the status is non-deterministic as well.

A probe's verdict must be its LAST statement (`[ "$FAIL" = 0 ]`), not its
output.
