# Function-key escape sequences: SS3 stops at F4, F5 and up are CSI tilde

F1-F4 are SS3: ESC O P, ESC O Q, ESC O R, ESC O S. The run STOPS there —
there is no ESC O T. F5 and up are CSI tilde forms: F5 = ESC [ 1 5 ~,
F6 = ESC [ 1 7 ~, F7 = ESC [ 1 8 ~, F8 = ESC [ 1 9 ~ (16 and 22 are
skipped, which is why the numbers look off by one from F5 onward).

Measured 2026-09-02 driving a real attached tmux client on a pty against
/Users/feb/dev/dotfiles/home/dot_config/tmux/tmux.conf. Writing ESC O T
expecting F5 does not error and does not arm the key table: five separate
assertions failed silently and read exactly like broken key bindings, when
the config was correct and only the probe was wrong. Verify a function-key
probe by asserting the SIDE EFFECT first — for tmux, that
`display-message -p "#{client_key_table}"` changed — before trusting any
later assertion in the same run.
