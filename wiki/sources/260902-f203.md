# chezmoi apply leaves a deployed file behind when its source is deleted; .chezmoiremove is the retirement mechanism

chezmoi apply does not remove a deployed target whose source file was deleted from the chezmoi source tree — the deletion is true of the repo and false of the machine. Measured 2026-09-02 with sourceDir /Users/feb/dev/dotfiles/home: after deleting four source files and running a scoped apply, all four targets were still present under ~/.config. The mechanism for retiring a file is a .chezmoiremove at the source root listing destination-relative paths (no dot_ prefix), which apply then enforces on every machine.
