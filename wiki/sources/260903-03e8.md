# The legacy board spelling can leave BOARD_DIRS without moving a board

Seven of the nine boards on this machine (manola, racer/.mi, dotfiles,
mitosys, shared, model, realm) are a real `pearde/` directory with a
`.pearde` symlink beside it. `zirkle/kern` and this repo hold a real
`.pearde/`; `/Users/feb/dev/infra`'s board is named `board`.

Measured 2026-09-03: all ten paths resolve to the identical board with the
legacy `pearde` name removed from `BOARD_DIRS`, because `board_link` reads
back through the compatibility symlink. So the 2026-09-02 two-spelling
branch can be deleted without upgrading, moving or renaming any board.
