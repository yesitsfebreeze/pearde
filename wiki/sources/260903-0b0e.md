# health.py list lines: one caller-shaped hazard is the score row printed by score itself

`health.py score --board` prints a trailing tally line (`1 scored · 1 on the ranking · …`) after the scored rows; anything consuming `list` output that greps loosely (e.g. for the file name) will also match the tally if the file name appears in it. Filter with `grep '^ *[0-9]'` before asserting on list/score output (probe check_pointer_not_verdict.sh, 2026-09-03).
