# obsidian-unhide can delete hidden files across an Obsidian Sync vault

Hiding a file routes through `DataAdapter.reconcileDeletion`, which Obsidian Sync propagates to every device as a deletion. Version 3.1.0 added a `protectSync` setting, on by default, that defers hiding while Sync is detected and flushes the deferred paths when protection is turned off.

The README's own warning is stronger than the setting: it is best-effort, it may not catch every case, and it says not to use the plugin if the data is very important. A pearde vault is the project root, so what it would be hiding is source.
