# Claude Code follows a symlinked skill directory, so one link installs a whole repo as a skill

`~/.claude/skills/coding-guidelines` is a symlink to
`/Users/feb/.agents/skills/coding-guidelines` — a directory, not a file — and
`coding-guidelines` is in the available-skills listing of a live session. So
Claude Code resolves a symlinked *directory* in a skills dir and loads the
`SKILL.md` inside it.

That makes `ln -s <repo> <skills-dir>/pearde` a complete install for any repo
whose root already holds `SKILL.md`, `README.md`, `index.md`, `references/`
and `resources/` — no folder of per-file links has to be fabricated.

A symlinked `SKILL.md` inside a real folder also loads: the pearde install on
this machine is `<skills-dir>/pearde/SKILL.md -> <repo>/references/skills/pearde.md`
and fires. Both hops are followed.
