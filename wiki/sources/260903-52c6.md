# obsidian-unhide needs Detect all file extensions, and its default rules freeze on big dot-folders

The plugin's README makes `Files & links > Detect all file extensions` (`app.json`'s `showUnsupportedFiles`) a precondition: without it the plugin does not work properly.

Its default `showingRules` exclude only `.git` and `.venv`. Every other dot-directory is walked the moment the plugin is enabled, and the README names the failure: Obsidian freezes, for a long time, on a vault holding a dot-folder with 100+ files. A pearde project has several — `.pearde/.lanes/` holds one full repo checkout per lane — so `.obsidian/plugins/unhide/data.json` must carry its own rules: `"+/"` to include hidden files, then `"-/\.lanes(?:\/|$)/u"` and the same for `.state`, `.claims` and `.graphify`.
