# obsidian-unhide's plugin id is unhide, not its repo name

Obsidian matches `.obsidian/plugins/<dir>` and the entries in `community-plugins.json` against `manifest.json`'s `id`. polyipseity/obsidian-unhide's id is `unhide`, so a bundle directory named for the repo loads nothing and an entry spelled `obsidian-unhide` enables nothing.

Release 3.1.0 (2026-08-27) publishes `main.js`, `manifest.json` and `styles.css` as release assets under a bare `3.1.0` tag — no `v` prefix. That is exactly the three files and the tag shape pearde's `install.sh` fetch loop already builds its URL from, so pinning it needed no new code.
