# Claude Code 2.1.259 skips a SKILL.md over 128KB and caps no filesystem description

Strings in the 2.1.259 binary:

- `` `SKILL.md` over 128KB is skipped `` — a file-size limit on the skill file
  itself.
- `description is longer than ${S} characters, the most a saved skill's
  description can hold` — this is the *skill-creation* tool's zod schema
  (`description:i().max(S)`) on proposals it saves, not a check on a SKILL.md
  read off disk. No length check on a filesystem description was found.

Measured beside it: across 500 SKILL.md files on this machine (user skills,
private skills, every installed plugin marketplace) the longest `description:`
is 1014 characters — `pearde-scout`. Nothing exceeds 1024, which reads as a
convention authors hold to rather than a limit the loader enforces.

Two skills in `~/.claude/skills` show in the listing with **no description at
all** while their neighbours show theirs: `rust-router`, whose description is
a YAML block scalar (`description: |-`), and `unsafe-checker`, whose
description is a double-quoted scalar full of `:` and `#[repr(C)]`. Two
samples, so a correlation rather than a rule — but the shape of the YAML
scalar, not its length, is what the two have in common.
