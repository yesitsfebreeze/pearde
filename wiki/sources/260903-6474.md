# the brief's health pointer names the note path, and no caller parses the line

health.py list prints, per file under the floor: score, file, worst axis, note path (or `no note at <path> — pearde health score writes one` when the note is missing from disk). Nothing downstream parses the line's shape: board/brief.py's health_of joins the raw lines whole, and doctor's health row reads ranking.md's frontmatter, never list's stdout — so the added column is purely additive (PRD enforce-pointer-not-verdict, spec01, proved by grep over every caller, 2026-09-03).
