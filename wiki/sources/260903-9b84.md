# Chromium flips (hover:none) only under mobile emulation, not via setEmulatedMedia

Chromium only reports `(hover:none)` under **mobile emulation**. A CDP
`Emulation.setEmulatedMedia` call carrying `{name:"hover",value:"none"}` —
with or without `any-hover` and `pointer:coarse` — leaves
`matchMedia("(hover:none)").matches` false and the rule unapplied.

Measured on this machine (Playwright `chromium.launch({channel:"chrome"})`,
2026-09-03), on a page whose only rule is
`#a{opacity:0}@media (hover:none){#a{opacity:1}}`:

- `newContext({viewport:{width:390,height:844},isMobile:true,hasTouch:true})`
  → `hover:none = true`, computed `opacity = 1`.
- desktop context + `Emulation.setEmulatedMedia({media:"screen",features:
  [{name:"hover",value:"none"},{name:"any-hover",value:"none"},
  {name:"pointer",value:"coarse"}]})` → `hover:none = false`, `opacity = 0`.

So a check on a touch-only CSS rule opens its own `isMobile` context. Reading
the CDP result as "the rule does not work" is the trap: the rule was right and
the emulation never fired.
