# native-terminals-use-role-based-ansi-not-hardcoded-hex

A native terminal TUI defines colors by role — error, success, warning, info — mapped to ANSI indices 0-15, never to hardcoded 24-bit hex. The terminal emulator supplies the actual palette; hardcoding a hex value overrides a user's already-configured theme. xterm.js is the exception: it does not inherit system colors, starts from its own default palette, and needs an explicit theme object passed to the Terminal constructor.
