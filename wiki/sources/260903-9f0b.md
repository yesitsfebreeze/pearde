# test a refusal before filtering the refused entries out

A refusal that first filters the refused entries out of its working set and then tests for "nothing left" turns "everything was refused" into an empty set that succeeds with rc 0 — test the refusal on the set as it arrived, before any filter. Measured on pearde dispatch.main 2026-09-03: a second `pearde run` on a fully-held board printed a 0-board order and exited 0 because the held-board filter emptied `entries` before the `not locks and entries` check.
