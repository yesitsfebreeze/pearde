# Obsidian's path: operator matches a substring of the file path, so a bare folder name hides a same-named folder anywhere

Obsidian's Search help documents `path:` as "Find text in file path" and
`file:` as "Find text in filename", both "Matches any file in the vault", and
its own example `path:"Daily notes/2022-07"` matches a portion of a path. It
is substring matching — not prefix, not exact.

Consequence for the graph view's filter: `-path:"memos"` hides BOTH the
authored `<board>/memos/` folder and the generated `<board>/wiki/memos/`
folder. A filter meant to hide only the authored records must spell enough of
the path to separate the two — `-path:"pearde/memos"`, which is also a
substring of `.pearde/memos` and so covers a board under either name.
