# rust-uses-system-malloc-so-valgrind-needs-no-special-setup

Valgrind's memcheck tracks Rust binaries out of the box because Rust uses system malloc by default — no jemalloc since 1.32 — so no jemalloc suppression file is needed before a first run. This matters even under a deny(unsafe_code) crate policy: dependency C code (libc, terminfo, parsing crates) and leak growth in a long-running process sit outside what the borrow checker can catch, so memcheck and massif still earn their place in the toolchain.
