# icon-swaps-animate-opacity-scale-and-blur-not-visibility

Swapping an icon (play to pause, check to spinner) animates opacity, scale, and blur together instead of toggling display or visibility. Use exactly scale 0.25 to 1, opacity 0 to 1, blur 4px to 0px; with motion/framer-motion installed drive it with transition: { type: "spring", duration: 0.3, bounce: 0 } — bounce is always 0. Without a motion library, keep both icons mounted, one absolute-positioned, and cross-fade with a cubic-bezier(0.2, 0, 0, 1) CSS transition to get both enter and exit for free.
