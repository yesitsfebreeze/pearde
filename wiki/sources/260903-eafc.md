# git archive HEAD into scratch is the cheap pre-edit baseline for a board-file footprint

A pass-two worker inherits a tree whose pass-one edits are already in it, so the pre-edit baseline has to be reconstructed. Where the footprint is a board file read by a plain node/python script that derives its root from its own location (dirname(fileURLToPath(import.meta.url)) + "../../.."), `git clone --no-hardlinks` is far more machinery than needed: `git archive HEAD <the paths the script reads> | tar -x -C <scratch>` gives a runnable pre-edit tree in seconds with no node_modules and no worktree registration, and the harness predicate runs there unchanged.

Measured in /Users/feb/dev/manola on 2026-09-03: exporting `pearde/prds/copy-lint src` at HEAD 2af8e44 and running `node pearde/prds/copy-lint/scan.mjs --ledger | grep -cE 'value drift.*cdemo\\.'` in the export printed 11, against 0 in the working tree — which is what proved the acceptance box discriminates rather than being a check that cannot fail.

It only works when the script resolves its own root; a harness that runs `cd "$(git rev-parse --show-toplevel)"` will walk out of a plain tar export, and needs a real worktree or a clone.
