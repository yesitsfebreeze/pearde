# terminal-rendering-diffs-two-buffers-and-flushes-once

A terminal renderer keeps a current and a next character-cell buffer, diffs them every frame, and writes only the changed cells as one batched flush. Writing cell-by-cell to stdout inside a loop causes flicker and tearing on real terminals. The alternate screen buffer (\x1b[?1049h) holds this diffed output so the user's scrollback stays untouched, and exit must restore cursor visibility, SGR state, and the main screen.
