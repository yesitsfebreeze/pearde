# pearde upgrade refused every board on the .pearde layout

`cmd_upgrade` computes `into = args.opt.get("dir") or planlib.BOARD_DIR` and
passes it to `unhide_board`, which raises `Refused` on any name starting with
a dot. `BOARD_DIR` has been `.pearde` since the 2026-09-02 revert, so the
call refused on every board. `cmd_vault` refused the same way.

The designated migration door was shut for a day, and `doctor.sh`'s `vault`
row named that exact command as its fix.
