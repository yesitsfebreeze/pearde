# mcp-tool-quality-is-graded-by-ten-verifiable-read-only-eval-questions

A finished MCP server ships with ten evaluation questions, each independent, read-only, and answerable by a single string comparison. The author solves every question themselves first — an eval that can't be answered by the tool's own designer isn't a fair bar for the agent using it. Questions must require multiple tool calls and real exploration, not a lookup a spec sheet would answer.
