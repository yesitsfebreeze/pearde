# nuxtlink-over-routerlink-auto-import-over-manual-clientonly-for-browser-apis

NuxtLink replaces RouterLink everywhere — ESLint enforces it — because it adds prefetching and SSR-safe navigation that RouterLink doesn't have. Composables, components, and utils under their respective directories auto-import with no manual import statement; if a component isn't picked up, it's outside components/, composables/, or utils/, or the dev server needs a restart after a new directory was added. SVGs in assets/icons/ auto-import as Vue components via nuxt-svgo, kebab-case filename mapped to PascalCase with a Svgo prefix. Any component that touches window/document, or whose render output differs between server and client, wraps in <ClientOnly> or defers the access to onMounted — skipping this produces a hydration mismatch, not a warning.
