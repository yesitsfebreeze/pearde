# canary-verification-depth-scales-with-diff-scope-not-a-fixed-checklist

Post-deploy verification depth is set by what the diff touched: a docs-only change skips verification entirely, a config-only change gets a status-code smoke check, a backend-only change gets console-error and perf checks, and any frontend change gets the full pass including a screenshot. A failed canary offers revert as one of three explicit options, not an automatic rollback.
