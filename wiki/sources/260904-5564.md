# script-setup-typed-props-with-withdefaults-usetemplateref-never-a-bare-ref

Every component is <script setup lang="ts"> — no Options API, no defineComponent — with a fixed section order: imports, props/emits/model, composables and injects, local state, functions, provides. Props use the TypeScript generic form (defineProps<{...}>()), and every optional prop gets an explicit undefined default via withDefaults — never left implicit. defineModel<T>({ default: ... }) replaces a manually wired prop-plus-emit pair for two-way binding. Template refs always go through useTemplateRef("name"); a bare ref(null) named after the element breaks the compiler's static analysis of the ref and is wrong even though it runs. Composables are use*-named, exported as named exports only (no default export), and always return a plain object — never an array; a module-level ref is the sanctioned way to share state across component instances. No <style> blocks — all styling is Tailwind utility classes, with multi-branch conditional class logic extracted into a computed rather than inlined in the template. An unused import, variable, or destructured prop is deleted before a task counts as done.
