# mcp-server-coverage-defaults-to-comprehensive-when-client-behavior-is-unknown

When unsure whether an agent needs broad API coverage or a handful of workflow tools, default to comprehensive endpoint coverage. Some clients compose primitives themselves through code execution; others need a higher-level workflow tool to get the same result in one call. Coverage is the safer default because it serves both client types — a workflow tool only serves the client that lacks composition.
