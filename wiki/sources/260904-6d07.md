# pearde doctor pads its category column, so a single-space grep for '<category> ok' never matches

`pearde doctor` right-pads its category column to a fixed width, so the category and its verdict are separated by several spaces, not one: `workflows   ok`. A verify assertion written as `grep -q 'workflows ok'` can never match and silently fails the block. Use `grep -qE 'workflows +ok'` (or match the verdict word alone) when asserting a doctor category is green.
