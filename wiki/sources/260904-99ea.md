# retro-diffs-against-exactly-one-prior-snapshot-not-an-absolute-baseline

Each retro run saves one JSON snapshot to a per-date, per-sequence file with a fixed metric schema, then the next run loads only the single most recent prior snapshot and reports deltas as a "Trends vs Last Retro" table. No prior snapshot means the comparison section is dropped, not backfilled or estimated — the report says "first retro recorded" instead.
