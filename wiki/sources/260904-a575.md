# return-result-reserve-panic-for-named-unrecoverable-states

Every fallible function returns Result<T, E>; panic!, unwrap(), and expect() are banned outside tests and cases where failure is provably impossible — replace them with `let Some(x) = opt else { return Err(...) }` for an expected-and-normal early exit, or unwrap_or_else for a computed default. thiserror builds library and crate-level error types: #[derive(Error)] gives Display for free, and #[from] on a variant wraps a lower layer's error into the caller's hierarchy without a manual From impl, so nested systems compose one enum per layer. anyhow stays in binaries only — never as a library's public return type, because anyhow::Result erases the caller's ability to match on error kind. `?` propagates by default over match chains; inspect_err/map_err log or reclassify an error without unwrapping it. Errors crossing a spawned task or an .await boundary must be Send + Sync + 'static.
