# measure-before-optimizing-then-cut-clones-and-collects-first

Golden rule: don't guess, measure — profile with cargo flamegraph (or samply on macOS) before changing anything, always against --release (a debug-build performance complaint is noise), and trust cargo bench only above roughly a 5% delta. Before profiling, two clippy lints already catch the common waste for free: redundant_clone (a clone whose value is never mutated, so it's identical to a borrow) and needless_collect (a .collect() immediately re-iterated by the next call). Pass an iterator (impl Iterator<Item = T>) into a function instead of collecting into a Vec just to hand it off — the iterator chain compiles to one fused loop either way, the intermediate collection is pure allocation. Box stack allocations over roughly 512 bytes rather than moving them by value. #[inline] earns its place only after a benchmark shows it helps — the compiler already inlines well without hints.
