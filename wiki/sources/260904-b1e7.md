# land-gates-an-irreversible-merge-behind-a-readiness-report-not-just-green-ci

CI passing does not authorize the merge. A separate readiness report aggregates review staleness (commits since the last review, flagged red past four), test freshness, changelog/version state, and PR-body accuracy into blockers versus warnings, and the merge only proceeds after explicit confirmation against that report. The merge is irreversible without a revert commit, so the gate sits specifically before it, not before CI.
