# prefer-borrowing-clone-only-when-ownership-is-truly-needed

Default every function parameter to a borrow — &T, &str over String, &[T] over Vec<T> — and clone only when a specific reason forces an owned copy: sharing across threads via Arc, caching a field for later return, a crate API contract that requires owned data, a builder consuming and returning self, or a snapshot comparison that needs two independent owned values. Never clone a reference argument to fake ownership inside a function — take ownership explicitly in the signature instead, so the caller decides. Clone late: hold the borrow as long as possible and only materialize the owned copy at the last point it's needed, not at the top of the function. Copy fits small, all-Copy-field, heap-free structs up to roughly 24 bytes (three 64-bit words) — never a struct holding a String or Vec. Cow<'_, T> covers a function that sometimes only reads and sometimes needs to own, without forcing every caller into one or the other.
