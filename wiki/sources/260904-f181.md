# The sr-only clip belongs on a div, never on a table

A `<table>` cannot carry the visually-hidden clip itself. The sr-only pattern
(position:absolute; width:1px; height:1px; overflow:hidden; clip-path:inset(50%))
assumes a block box. A table box takes its min-content width whatever `width`
says: the table stays as wide as its columns, overflows the document, and gives
every viewport a horizontal scrollbar. Measured on /knowledge/llm-model-selection:
document scrollWidth 1711 against a 1440 client, and 905 against 390.

The fix is a wrapping `div` carrying the clip with the `table` plain inside — the
table keeps its semantics and the 1px box is real.

Catch it in a headless pass by comparing documentElement.scrollWidth against
clientWidth. No lint rule, no type check and no served-HTML check sees it.
