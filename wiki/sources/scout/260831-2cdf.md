# What the curated reading list says to steal, per tree

The star chart is discovery, never value. Three genres in rising order: link-lists (use the index, move on), case-study corpora (the reading itself), reference implementations (the copying itself). An entry survives one question — *which file in which tree changes because we read this*.

- **codex** (117k): the turn loop — interrupt a running tool, stream partial output, enforce permission boundary without losing the turn's record.
- **mem0** (64k): `add` → extract-facts → consolidate-into-graph; consolidation triggers comparable to our own ingest→record compression. Production-scale answer to our problem.
- **claude-mem** (92k): capture-everything compress-later — read as the *reductio* of our tick-requires-evidence stance: what their compression loses, what their injection does.
- **nanochat** (58k): the only short repo showing every stage between a text corpus and a served model — the shape of the corpus→weights compile.
- **lm-evaluation-harness** (14k) / **promptfoo** (25k): the two-arm gate — one human-authored question set, two model arms, gap as the reading. promptfoo's assertions-as-data framing records the gate as a file, which DOGMA 8 prefers.
- **nextest** (3.2k): process-per-test supervision — kill a hung test *and its grandchildren*.
- **sled** (9.1k): crash-recovery proofs without real crashes — seeded fault injection, exhaustive partial-write tests.
- **Anti-list discipline**: ECC (243k), graphify (110k), ponytail (110k) — star velocity without a describable mechanism is the hype signature. `langchain`/`crewAI` teach the trade we already declined.

Full table with per-tree mappings lives in `resources/scout/reading-list.md` — never copied here; the distilled takeaway is this note, the list is the citation.
