# What the 2026-08-26 and 2026-08-28 sweeps picked, and on which axes

- **Recursive search over a source tree → `ripgrep`** (strong). Four axes agree: brew 85,537/30d, arch 78.63%, popcon 13,329, 122 distros. Control: `fd` ranks second everywhere on a different job — the axes measure adoption, not fashion. Overturned by: a `depsdev` gap of a year or an `osv` advisory → moves to `ugrep`.
- **One widget API → terminal + web + native desktop → no exact answer; recorded as a rejection** (strong). Dioxus was the one close match and its TUI platform was *removed* (`dioxus-tui` gone from the monorepo, last publish 2024-02). Survivors: `ratatui+ratzilla` (Rust) and `Textual+textual-web` (Python) — each terminal+web from one widget tree, neither with a windowed-desktop renderer. Feature-gating per platform is native to both (`#[cfg]`, Textual driver checks).
- **Train + run a small model inside a Rust harness → `candle`** (strong, as a confirmation that had never been measured). Beats `ort` (inference-only — cannot run `apply_gradient`, so its 2.5× install lead measures a job we are not doing), `tch` (links libtorch — against single-binary packaging), `burn` (real rival: 6.8× behind on installs, better backend story via CubeCL). Hygiene axis thin: 5 of 6 have no scorecard — the corner sits outside the OpenSSF ecosystem.
- **Route gotchas**: `repology fd` returns 0 because the project is `fd-find` — a zero means the name is wrong, not that it is unpackaged. `route.sh crates` is fuzzy and swamped by short queries — query a distinctive substring (`onnxruntime` finds `ort`).
