# What the 2026-08-26 sweep decided about free ranking access

- **Star momentum for repos we do not own**: the GitHub stargazers API is restricted since 2026-06-30. The only real series is our own `snapshots/*.tsv` diffed by `scout.sh delta`. OSS Insight (30-star tail) is a discovery channel, never a ranking. star-history renders SVG — a picture, not a series.
- **Web search without a key**: free tier has closed almost completely. `api.marginalia.nu/public/search/<q>` (200, JSON, CC-BY-NC-SA) and `lite.duckduckgo.com/lite/` (HTML, 10 links parseable) are what survive. All 8 public SearXNG instances 429 or refuse `format=json`. Volume = own SearXNG container. Brave/Exa/Tavily = key + billing; `grep.app` 429s on first anonymous call.
- **Page as text**: `r.jina.ai/<url>` returns markdown with title + date, no key at low volume — the only extractor measured, so `weak` until a head-to-head against trafilatura/readability.
- **Overturn conditions recorded per finding**: a public SearXNG answering `format=json` twice in a week reopens search; GitHub restoring the stargazers timeline makes snapshots redundant for un-sampled repos.
- **Open jobs** (asked, not measured): local vs hosted markdown extraction (paywall/cookie-wall/JS fidelity), polite bulk fetch of one domain, embedding model for local retrieval.

Source: `resources/scout/findings.md` rows "web search from a script, no API key", "star momentum", "a page as text". Every cell reproducible via `route.sh <id> <query>`.
