# grep here is ugrep, and a needle written from prose can never fire

This machine's `grep` is ugrep 7.8.4 (aarch64-apple-macosx), installed over the base system's BSD grep. BRE alternation (`\\|`) therefore works here, so the usual darwin warning about BSD BRE having no alternation does not bite on this box.

The live hazard is the opposite one, and it is not a portability bug: a needle that alternates correctly can still never match, because it was written against the *prose* shape of a line rather than the shape the code prints. Measured on `delta-names-the-missing-day`: a verify block asserted `grep -q '^delta ·\\|^gap:'` while `scout.sh` actually prints `delta 7 · diffed against …`. The `^delta ·` half can never fire; a mutation that leaked the window line on the `delta 0` path left the block at exit 0.

Test a needle by mutating the code to produce the thing it forbids, not by reading it. A check that cannot fail reads exactly like a check that passes.
